## راهنمای آنلاین کردن داشبورد بازار سرمایه

### معماری کلی

سیستم شما همان‌طور که الان کار می‌کند، بدون هیچ تغییری، به کار خود ادامه می‌دهد.
یک اسکریپت کوچک، بعد از هر اجرا، فقط خروجی‌های نهایی (جدول و نمودار) را به‌صورت خودکار به یک مخزن آنلاین ارسال می‌کند.
یک سرویس رایگان، آن مخزن را می‌خواند و سایت شما را از روی آن می‌سازد.

پایگاه‌داده و رمز عبور آن هیچ‌وقت آنلاین نمی‌شود.

---

### مرحله ۱ — ساخت حساب و مخزن

ابتدا یک حساب رایگان بسازید.

آدرس ثبت‌نام:

```
https://github.com
```

سپس یک مخزن جدید بسازید. نام پیشنهادی برای مخزن:

```
market-dashboard
```

سه چیز را داخل این مخزن قرار دهید:

```
app.py
requirements.txt
web_export/   (یک پوشه‌ی خالی)
```

در نهایت، روی همان سیستمی که برنامه‌های تحلیلی را اجرا می‌کنید، این مخزن را دریافت کنید.
دستور دریافت (این خط را در خط فرمان اجرا کنید):

```
git clone https://github.com/USERNAME/market-dashboard.git C:\market-dashboard
```

به‌جای بخش USERNAME در دستور بالا، نام کاربری خودتان در گیت‌هاب را قرار دهید.

---

### مرحله ۲ — یک خط اضافه به برنامه‌ی اول

برنامه‌ی دوم شما از قبل جدول خروجی هم می‌سازد و نیازی به تغییر ندارد.

برنامه‌ی اول شما فقط تصویر می‌سازد. برای این‌که جدول و نمودار تعاملی هم داشته باشید،
یک خط به تابعی که داده را از پایگاه‌داده می‌خواند اضافه کنید.

این خط را، دقیقاً قبل از پایان آن تابع، اضافه کنید:

```python
df.to_csv(
    os.path.join(self.output_folder, "hot_money2_export.csv"),
    index=False, encoding="utf-8-sig"
)
```

### مرحله ۳ — همگام‌سازی خودکار

فایلی به نام همگام‌ساز که برایتان آماده شده را داخل همان پوشه‌ی مخزن قرار دهید.

نام این فایل:

```
web_sync.py
```

داخل این فایل، در همان خطوط ابتدایی، یک مسیر با نام زیر مشخص شده است. آن را با مسیر واقعی سیستم خودتان جایگزین کنید:

```
REPO_DIR
```

سپس یکی از این دو روش را انتخاب کنید تا این فایل به‌طور خودکار بعد از هر تحلیل اجرا شود:

**روش اول — اضافه‌کردن دو خط به انتهای هر دو برنامه‌ی تحلیلی:**

```python
import subprocess
subprocess.run(["python", r"C:\market-dashboard\web_sync.py"])
```

**روش دوم — زمان‌بندی مستقل:**
با برنامه‌ی زمان‌بند سیستم‌عامل خودتان (در ویندوز: Task Scheduler)، هر چند دقیقه یک‌بار همین فایل را اجرا کنید.

برای این‌که ارسال خودکار بدون وارد کردن رمز هر بار انجام شود، یک‌بار باید یک کلید دسترسی از گیت‌هاب بسازید.
مسیر ساخت این کلید در حساب گیت‌هاب شما:

```
Settings → Developer settings → Personal access tokens
```

### مرحله ۴ — انتشار رایگان سایت

آدرس سرویس انتشار رایگان:

```
https://share.streamlit.io
```

با همان حساب گیت‌هاب خودتان وارد این آدرس شوید.
گزینه‌ی ساخت سایت جدید را انتخاب کنید و نام مخزن خود را وارد کنید:

```
market-dashboard
```

نام فایل اصلی سایت را هم وارد کنید:

```
app.py
```

روی دکمه‌ی انتشار بزنید. بعد از یک تا دو دقیقه، سایت شما آماده می‌شود، با آدرسی شبیه به این:

```
https://market-dashboard-yourname.streamlit.app
```

این آدرس کاملاً رایگان است.

---

### فایل‌های این پکیج

| فایل | کاربرد |
|---|---|
| app.py | داشبورد وب تعاملی |
| web_sync.py | جمع‌آوری خروجی‌ها و ارسال به مخزن آنلاین — روی سیستم محلی اجرا می‌شود |
| requirements.txt | فهرست کتابخانه‌های لازم برای اجرای سایت |

### به‌روزرسانی داده‌ها

سایت هر ۶۰ ثانیه یک‌بار داده‌های تازه را از مخزن می‌خواند.
اما داده‌ی تازه فقط زمانی وجود دارد که همان مرحله‌ی ۳ (همگام‌سازی خودکار) روی سیستم شما در حال اجرا باشد.
یعنی سرعت واقعی به‌روزرسانی، به فاصله‌ی زمانی اجرای برنامه‌های تحلیلی و همگام‌ساز روی سیستم خودتان بستگی دارد.
