## راهنمای انتشار داشبورد روی گیت‌هاب پیجز

### معماری کلی

سیستم شما همان‌طور که الان کار می‌کند، بدون هیچ تغییری، به کار خود ادامه می‌دهد.
یک اسکریپت کوچک، بعد از هر اجرا، فقط خروجی‌های نهایی (جدول و نمودار) را به‌صورت خودکار به یک مخزن آنلاین ارسال می‌کند.
یک صفحه‌ی وب ساده، همان مخزن را می‌خواند و نمودارها را مستقیماً داخل مرورگر کاربر رسم می‌کند — بدون نیاز به هیچ سروری.

این روش نسبت به Streamlit یک مزیت مهم دارد: چون صفحه فقط یک فایل ساده است و از زیرساخت گیت‌هاب استفاده می‌کند، برخلاف آدرس‌های streamlit.app، معمولاً بدون نیاز به فیلترشکن هم در دسترس است.

پایگاه‌داده و رمز عبور آن هیچ‌وقت آنلاین نمی‌شود.

---

### مرحله ۱ — ساخت مخزن گیت‌هاب

- یک حساب رایگان در `github.com` بسازید (اگر ندارید).
- یک مخزن جدید بسازید، مثلاً با نام `market-dashboard` (این‌بار باید عمومی/Public باشد، چون گیت‌هاب پیجز فقط روی مخازن عمومی رایگان است).
- فایل `index.html` و یک پوشه‌ی خالی به نام `web_export` را داخل آن قرار دهید.
- روی سیستم محلی خودتان این مخزن را دریافت کنید:

```
git clone https://github.com/USERNAME/market-dashboard.git C:\market-dashboard
```

### مرحله ۲ — یک خط اضافه به برنامه‌ی اول

برنامه‌ی دوم شما از قبل خروجی جدول (CSV) هم می‌سازد و نیازی به تغییر ندارد.

برنامه‌ی اول شما فقط تصویر می‌سازد. برای این‌که جدول و نمودار تعاملی هم داشته باشید،
این خط را در تابعی که داده را از پایگاه‌داده می‌خواند اضافه کنید:

```python
df.to_csv(
    os.path.join(self.output_folder, "hot_money2_export.csv"),
    index=False, encoding="utf-8-sig"
)
```

### مرحله ۳ — همگام‌سازی خودکار

فایل `web_sync.py` را داخل همان پوشه‌ی پروژه‌ی تحلیلی خودتان قرار دهید (همان‌جایی که الان است، تغییری نمی‌خواهد).
مقدار `REPO_DIR` در بالای فایل باید به مسیر مخزنی که در مرحله‌ی ۱ ساختید اشاره کند.

سپس یکی از این دو روش را انتخاب کنید تا این فایل بعد از هر تحلیل، به‌طور خودکار اجرا شود:

**روش اول — اضافه‌کردن دو خط به انتهای هر دو برنامه‌ی تحلیلی:**

```python
import subprocess
subprocess.run(["python", r"C:\market-dashboard\web_sync.py"])
```

**روش دوم — زمان‌بندی مستقل:**
با Task Scheduler در ویندوز، هر چند دقیقه یک‌بار همین فایل را اجرا کنید.

### مرحله ۴ — فعال‌سازی گیت‌هاب پیجز

- وارد صفحه‌ی مخزن خودتان در گیت‌هاب شوید.
- به بخش `Settings` بروید، سپس از منوی سمت راست گزینه‌ی `Pages` را انتخاب کنید.
- زیر عنوان `Build and deployment`، در قسمت `Branch`، شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب کنید و `Save` بزنید.
- بعد از حدود یک دقیقه، آدرس سایت شما بالای همان صفحه نمایش داده می‌شود، چیزی شبیه به این:

```
https://USERNAME.github.io/market-dashboard/
```

این آدرس کاملاً رایگان است.

---

### فایل‌های این پکیج

| فایل | کاربرد |
|---|---|
| `index.html` | داشبورد وب تعاملی — همین فایل باید در گیت‌هاب پیجز منتشر شود |
| `web_sync.py` | جمع‌آوری خروجی‌ها و ارسال به مخزن آنلاین — روی سیستم محلی اجرا می‌شود |

### به‌روزرسانی داده‌ها

سایت هر بار که کاربر صفحه را باز کند یا رفرش کند، تازه‌ترین نسخه‌ی فایل‌های داخل مخزن را می‌خواند.
یعنی سرعت واقعی به‌روزرسانی، فقط به فاصله‌ی زمانی اجرای برنامه‌های تحلیلی و `web_sync.py` روی سیستم خودتان بستگی دارد — نه به هیچ محدودیت کش دیگری.
